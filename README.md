NVCloud-Android

Cloud Android tự dựng, ưu tiên miễn phí và tối ưu điều khiển qua mạng yếu.

Mục tiêu

- Chạy Android bằng redroid.
- Ưu tiên phiên sử dụng khoảng 6 giờ.
- Hỗ trợ điều khiển từ xa.
- Tối ưu độ phân giải, FPS và bitrate.
- Chuẩn bị khả năng chạy Minecraft qua launcher Android tương thích.

Yêu cầu

- Máy chủ Linux tương thích với redroid.
- Hỗ trợ kernel Binder.
- Docker và các quyền cần thiết.
- GPU tương thích nếu muốn tăng tốc đồ họa.

Lưu ý

GitHub Actions chỉ dùng để kiểm tra và build cấu hình, không phải máy chủ Android chạy game.

Chưa có máy chủ chạy Android. Cần kiểm tra môi trường miễn phí trước khi triển khai.

Không công khai mật khẩu, token hoặc thông tin truy cập máy chủ.
